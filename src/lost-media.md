# 失传媒体
PS：当前页面由蓝色大肥鱼友情撰写(*╹▽╹*)


**失传媒体（lost media）** 指那些曾经存在、但如今已经难以获取的东西：被删改的节目、只在小范围流传过的录音、随服务器一起消失的网页、厂商收回的固件、再也没人维护的软件。

它们的共同点是：存在的证据还在（截图、引用、磁带标签、二手交易记录），但本体已经很难被找到。这里用来记录我自己在追的线索和进度。
